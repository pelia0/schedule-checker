# AGENTS.md — правила для роботи з Schedule Checker Bot

## Межі змін

- Працюємо з локальною копією в D:\t22checker.
- Серверна стабільна версія не змінюється і не перезапускається без окремого
  явного дозволу власника.
- Не комітити та не виводити в логи TELEGRAM_TOKEN, приватні chat_id або інші
  секрети з .env.

## Джерела даних

Код не повинен містити захардкоджений перелік пар, викладачів чи предметів.
Актуальні джерела задаються змінними BASE_SCHEDULE_CSV_URL,
SUBJECTS_CSV_URL, SEMESTER_CSV_URL і REPLACEMENTS_CSV_URL.

Аркуш розкладу має по два рядки на кожен час: верхній — НАД РИСКОЮ, нижній —
ПІД РИСКОЮ. Порожній нижній рядок означає, що заповнений верхній діє щотижня.
Якщо обидва рядки різні, вибір робиться за датою з аркуша семестру.
Позначки ---, ВІЛЬНА, ВІКНО, НЕМАЄ, ВІДМІНЕНО та СКАСОВАНО означають вікно.

## Таблиця замін

Заміни зіставляються за датою, групою та номером пари. Повна назва предмета не
є ключем: у джерелі допустимі скорочення, нестандартні назви й помилки.
Скорочення та повні назви беруться з аркуша предметів. Невідомі значення треба
показувати в попередженні, а не мовчки викидати.

Розбір групи має бути граничним: Т-32, T-32, Т32 і різні тире/пробіли
дозволені, але ПТ-32 і Т-321 — це інші групи. Після нового явного заголовка
іншої групи рядки-продовження не можуть залишатися прив'язаними до Т-32.

## Telegram і планувальник

- Анонс розкладу та привітання з днем народження — різні повідомлення.
- Час за Києвом: наступний навчальний день анонсується о 17:00 (у п'ятницю —
  понеділок), дні народження — о 08:00.
- Один запуск розкладу на дату: маркер зберігається тільки після успішної
  відправки.
- Відправка має мати один цільовий chat_id; не створювати похідні дублікати
  на кшталт додавання префікса -100.
- Приватний тест дозволений лише через PRIVATE_TEST_CHAT_ID або знайдений
  username; він ніколи не має fallback на CHANNEL_ID.

## Перевірка

Перед змінами та перед передачею результату запускати:

~~~powershell
rtk python -m py_compile bot.py schedule_announcements.py
rtk python -m unittest -v test_schedule_announcements.py
~~~

Для перегляду повідомлення без відправки:

~~~powershell
rtk python bot.py --preview-schedule [YYYY-MM-DD]
~~~

Для приватного тесту:

~~~powershell
rtk python bot.py --test-schedule
~~~

Команда приватного тесту вимагає заповненого токена й доступу до Telegram. Її
не запускати автоматично під час unit-тестів.
